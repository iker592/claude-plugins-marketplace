## Planning Frameworks

### SMART Goals
- **Specific** - Clear and well-defined
- **Measurable** - Quantifiable progress
- **Achievable** - Realistic given constraints
- **Relevant** - Aligned with larger objectives
- **Time-bound** - Defined deadline

## Task Examples

### Task: Plan New Startup Feature

**Execution:**
1. **Discovery:**
   - What feature? Why now? Who needs it?
   - Current startup status?
   - Time available? (Iker: ~10hrs/week side project time)

2. **Analysis:**
   - Technical complexity → Estimate 40 hours
   - Skills needed → Iker has most, may need to learn X
   - Dependencies → Needs Y completed first
   - Risk → User research not validated

3. **Planning:**
   ```markdown
   # Feature: [Name]

   ## Objective
   Build and deploy [feature] to solve [problem] for [users]
   by [date].

   ## Success Metrics
   - Feature deployed to production
   - 10 users testing within 1 week
   - Positive feedback from 70%+ users

   ## Milestones
   1. Design & spec (Week 1) - 5 hours
   2. Core implementation (Week 2-3) - 20 hours
   3. Testing & polish (Week 4) - 10 hours
   4. Deployment (Week 5) - 5 hours

   ## Weekly Breakdown
   - Week 1: Design mockups, write specs, user flow
   - Week 2: Backend API, data models
   - Week 3: Frontend components, integration
   - Week 4: Testing, bug fixes, documentation
   - Week 5: Deploy, monitor, gather feedback

   ## Time Allocation
   10 hours/week × 5 weeks = 50 hours total
   - Saturday: 4 hours
   - Sunday: 4 hours
   - Weeknights: 2 hours (when energy allows)

   ## Risks & Mitigation
   - Risk: Technical complexity underestimated
     → Mitigation: Add 1-week buffer
   - Risk: Full-time job suddenly busy
     → Mitigation: Can stretch to 7 weeks if needed

   ## Integration
   - Fits with 2026 goal: "Launch successful side project"
   - Doesn't conflict with fitness (different time slots)
   - Learning goal: Practice skill X

   ## Review Checkpoints
   - End of Week 1: Design approved?
   - End of Week 3: Core features working?
   - End of Week 5: Deployed and tested?
   ```

4. **Save to:** `Projects/Startup/features/feature-name-plan.md`
